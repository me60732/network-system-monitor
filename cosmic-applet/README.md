# cosmic-applet — Network System Monitor Desktop Panel Applet

A Cosmic desktop panel applet that displays system metrics from all Linux machines on your local network in a single unified view. No SSH or manual login required — each remote machine runs a lightweight systemd service (`nmd-service`) that pushes rkyv-encoded, HMAC-SHA256 authenticated UDP packets to the desktop applet every 2 seconds.

## Features

- **Panel Widget**: Single-line Cosmic panel showing local CPU, memory, disk, network, uptime, GPU VRAM, and temperature stats with color thresholds at 60% (yellow) / 80% (red).
- **Grid Window**: Click-to-expand window listing all remote machines in a grid layout — one row per machine with status indicators (● online / ○ offline/pending) and color-coded progress bars.
- **Secure UDP Protocol**: HMAC-SHA256 authentication + replay protection via timestamp freshness (< 10s) and per-machine sequence number tracking.
- **TOML Configuration**: Extends minimon-applet's format with per-machine checkbox metric selection, auto-expansion preferences, and localhost default entry.

## Development

### Prerequisites

- Rust toolchain (rustc 1.74+) — matches workspace `rust-version`
- Cosmic desktop environment development headers (`cosmic` crate v0.6)

just build-release

just install

## Architecture Integration Points

This crate integrates with the rest of the workspace as follows:

| Component       | Source Crate    | Consumed By          | Purpose                          |
|-----------------|-----------------|----------------------|----------------------------------|
| `MetricPacket`  | `nmd-service/src/packet.rs` | `udp_receiver.rs` | rkyv-serialized UDP payload with HMAC-SHA256 + replay protection |
| Metric structs  | `metrics-core/src/*.rs`     | `panel_widget.rs`  | CPU, memory, disk, network, uptime, GPU, temperature stats for local display |
| `ServiceConfig` | `nmd-service/src/config.rs` | (reference only)    | Shared config format conventions for machine_id + secret key paths |

## Security (Worf Phase 1A)

- **Authentication**: All incoming UDP packets are HMAC-SHA256 verified using a pre-shared key at `/etc/nmd/secret.key`.
- **Replay Protection**: Timestamp freshness check (< 10s old) + monotonic sequence number tracking per `machine_id`.
- **Secret Storage**: Key must be exactly 32 bytes with `0600` permissions, generated by the install script.
